# Meta Review

This folder evaluates the exploratory analysis outputs for two questions:

1. How well does each result fit the project?
2. How should each result be shown most effectively?

The project boundary is non-negotiable: all results describe benchmark mentions on public frontier-model release pages, not model capability.

## Shared Evaluation Criteria

| Criterion | Meaning |
| --- | --- |
| Project fit | Does the result advance the repository's core question about benchmark emphasis, provider strategy, or benchmark evolution? |
| Novelty | Does it add a new lens beyond the existing README charts? |
| Data support | Are the claims reproducible from current CSVs with clear denominators and resolution? |
| Risk of overclaiming | Could readers mistake the result for model capability, intent, or causal evidence? |
| Taxonomy dependency | Does the result rely heavily on `needs_review` facets or ambiguous source-author fields? |
| Presentation value | Can it be shown clearly with a compact chart/table and a short explanation? |
| Readiness | Is it suitable for README now, after small edits, or only as appendix/research backlog? |
