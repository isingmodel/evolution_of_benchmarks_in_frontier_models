# Historical Meta Review

This folder preserves qualitative reviews of the exploratory analyses: project
fit, presentation choices, taxonomy dependence, and the risk of overclaiming.
The reviews were written against an earlier snapshot with releases through
July 2026. Their numeric quotations, rankings, and readiness judgments are
**historical**, even where their source analysis CSVs have since been regenerated.

For current evidence and priorities, start with the
[project overview](../project_overview/README.md) and
[current analysis synthesis](../SYNTHESIS.md).
[SYNTHESIS.md](SYNTHESIS.md) here is an archived editorial synthesis, not the
source of current README claims. Review scores are qualitative judgments, not
additional measurements or completed source/facet audits.

## Criteria retained for future reviews

| Criterion | Question |
| --- | --- |
| Project fit | Does the result explain benchmark reporting or its evolution? |
| Data support | Are current inputs, units, denominators, and cutoffs reproducible? |
| Risk of overclaiming | Could readers confuse reporting with capability, intent, or causation? |
| Taxonomy dependency | Does the result depend on provisional facets or unresolved attribution? |
| Presentation value | Can evidence and its limits be shown clearly? |
| Readiness | Is the claim supported now, or does it require additional source review? |

The newer overview adds announcement-level sensitivity, complete calendar
follow-up cohorts, and explicit confidence-versus-acceptance coverage. Those
changes supersede older recommendations to lead with broad “work simulation”
or pooled OpenAI-linked growth claims.
